# Stuck Stack

A personal task tracker for things you're stuck on.

**Live app:** https://uzilan.github.io/stuckstack/

## Features

- Push tasks onto a stack, pop them off when done
- Drag and drop to reorder
- Tags — drag from sidebar onto tasks
- Frustration level slider with animations
- Expandable description and log per task
- Multiple named tabs (stacks)
- Everything saved in localStorage — no server needed

## Development

```bash
npm install
npm run dev
```

## Build

Produces a single self-contained `dist/index.html`:

```bash
npm run build
```
